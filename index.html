Most Used Daily Commands

These are the ones you’ll use every day

Everyday workflow

git status[check working tree state]
git add .[stage all changes]
git commit -m "message"[save staged changes]
git push[upload commits to remote]
git pull[download latest changes]
git branch[show local branches]
git switch <branch>[switch to another branch]
git log --oneline[view recent commit history]
git diff[show changes between files or commits]
This is the core loop for most daily Git work: check status, stage changes, commit, push, and pull before moving on.

Tier 1: Daily Essentials

Learn these first

Core commands

git init[create a new repository]
git clone <url>[copy a repository from remote]
git status[check repository state]
git add <file>[stage one file]
git add .[stage all changes]
git commit -m "message"[save staged changes]
git push[upload commits]
git pull[download and merge remote updates]
git log[view commit history]
git diff[see pending changes]

Tier 2: Branching

Work safely in parallel

Branch commands

git branch[list branches]
git branch <name>[create a new branch]
git checkout <branch>[switch branches]
git checkout -b <name>[create and switch branch]
git switch <branch>[switch to a branch]
git switch -c <name>[create and switch branch]
git merge <branch>[combine branch changes]
git branch -d <name>[delete a merged branch]
git branch -D <name>[force delete a branch]

Tier 3: Undoing and Fixing Mistakes

Recover without panic

Safe recovery tools

git restore <file>[restore a file from the index]
git checkout -- <file>[discard file changes]
git reset <file>[unstage a file]
git reset --soft HEAD~1[undo last commit and keep changes]
git reset --mixed HEAD~1[undo last commit and unstage changes]
git reset --hard HEAD~1[discard last commit and changes]
git revert <commit>[create a safe undo commit]
git commit --amend[change the last commit]
git stash[temporarily save changes]
git stash pop[restore stashed changes]
git stash list[show saved stashes]
git clean -fd[remove untracked files]

Tier 4: Remote and Collaboration

Keep teammates in sync

Collaboration commands

git remote -v[list remote repositories]
git remote add origin <url>[connect a remote]
git remote remove <name>[remove a remote]
git fetch[download remote changes]
git push -u origin <branch>[publish a branch to remote]
git push origin --delete <branch>[delete a remote branch]
git pull --rebase[update by replaying local commits]

Tier 5: Inspecting History

Understand what changed

History and inspection

git log --oneline[show compact commit history]
git log --graph --all[view branch history graph]
git show <commit>[display commit details]
git blame <file>[see who changed each line]
git diff <branch1> <branch2>[compare branch contents]

Tier 6: More Advanced

Use when the situation demands it

Advanced workflows

git rebase <branch>[reapply commits onto another branch]

git cherry-pick <commit>[apply a specific commit]
git tag <name>[create a release tag]

git bisect[find the bad commit]

GitHub-Specific Concepts

Beyond raw git commands
  • Pull Requests (PRs) — propose merging a branch and get it reviewed.
  • Forking — copy someone else’s repository into your own account.
  • .gitignore — tells Git what should never be tracked, like node_modules/ or .env.
  • GitHub Actions — automates workflows and CI from git events.
A practical note: learn Tier 1 and Tier 2 by using them daily, keep this page as a reference for the rest, and only dive deeper when a real problem requires it.

Additional Useful Commands

Less common, but handy when the need arises

Configuration & setup

git config --global core.editor "code --wait"[set VS Code as the default editor]
git config --list[view current Git settings]
git config --global alias.st status[create a shortcut alias]
git config --global init.defaultBranch main[set the default branch name]

Searching and filtering

git grep "searchTerm"[search tracked files for text]
git log --author="name"[filter commits by author]
git log --since="2 weeks ago"[filter commits by date]
git log --grep="fix"[search commit messages]
git log -- <file>[view history for one file]
git log -p[show diffs for each commit]
git shortlog -sn[summarize commits per author]

Comparing & finding things

git describe[show a human-readable commit name]
git rev-parse HEAD[print the current commit hash]
git ls-files[list tracked files]
git show HEAD~2:file.txt[view a file from two commits ago]

Patch-based workflows

git format-patch -1 HEAD[turn a commit into an email patch]
git apply patch.diff[apply a patch file]
git am patch.mbox[apply a mailbox of patches]

Working with multiple checkouts

git worktree add ../other-folder branch-name[check out a branch in another folder]
git worktree list[show all active worktrees]

Large or partial repos

git sparse-checkout set folder1 folder2[check out only selected folders]
git archive --format=zip HEAD -o out.zip[export the repo as a zip file]
git bundle create repo.bundle main[package a repo into a transferable file]

Maintenance / repair

git fsck[check repository integrity]
git gc[clean up and optimize the repository]
git reflog expire --expire=now --all[clear reflogs immediately]

Submodules & subtrees

git submodule add <url> path/[add another repo as a submodule]
git submodule update --init[initialize submodule contents]
git subtree add --prefix=lib <url> main[bring in another repo as a subtree]

Notes

git notes add -m "note"[attach a note to a commit]

Rare / Edge-Case Commands

Mostly for unusual or advanced situations

Advanced workflow helpers

git commit --fixup=<commit>[mark a commit as a fix for an earlier one]
git rebase -i --autosquash[apply fixup commits automatically during rebase]
git rerere[reuse a previous conflict resolution]
git range-diff <r1> <r2>[compare two ranges of commits]
git merge-tree[preview a merge without applying it]
git replace[temporarily swap one object for another]
git verify-commit / verify-tag[check GPG signatures]
git commit -S -m "message"[create a signed commit]
git maintenance start[enable automatic repository maintenance]

Plumbing commands

git hash-object <file>[compute the hash of file content]
git cat-file -p <hash>[inspect a raw Git object]
git ls-tree <tree>[list the contents of a tree object]
git write-tree[create a tree object from the index]
git update-index[manually update the staging area]
git count-objects[show repository size statistics]
git prune[remove unreachable objects]
git repack[repackage objects for efficiency]
